# DealVault

DealVault is an Escrow-Based Freelancing Platform developed using Spring Boot, JSP, MySQL, and Bootstrap.

The platform allows clients to post projects, freelancers to apply for projects, and payments to be securely locked in escrow until project completion.

---

## Features

- User Authentication (Client / Freelancer)
- Client Dashboard
- Freelancer Dashboard
- Project Creation
- Apply for Projects
- Freelancer Selection
- Escrow Payment Locking
- Project Completion Workflow
- Payment Release System
- Wallet Balance Tracking
- Responsive UI using Bootstrap

## Project Workflow

1. Client creates a project
2. Freelancers apply for the project
3. Client selects a freelancer
4. Project budget gets locked in escrow
5. Freelancer completes the work
6. Client approves completion
7. Escrow releases payment to freelancer wallet
